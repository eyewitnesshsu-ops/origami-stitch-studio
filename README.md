# 折纸编织图解生成器 · Origami Stitch Studio

设置折面宽、折线数、平褶段和模块数，选择形状，自动生成折纸编织的图解、逐行文字解与立体模拟。

**在线使用：** https://origami-stitch-studio.pages.dev/

**编织工具箱：** https://knitting-toolbox.pages.dev/

## 功能

- 长方形 A / B、三角形尖角起 / 收、单边左 / 右加针，共六种形状
- 参数即时计算，生成图解与逐行文字解
- 立体模拟、图解缩放、摘要 / 完整模式切换
- 图解与文字解分别下载为 PNG
- [使用指南](guides/origami-stitch-guide.pdf)

本工具是独立的静态网页，仓库根目录的 `index.html` 即为生成器。工具箱主页仅提供入口，不参与生成器的运行。
